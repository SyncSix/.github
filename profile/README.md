# Olá, nós somos a SyncSix! 👋

**Equipe de Desenvolvimento de Software**

Somos uma equipe composta por 6 membros, formada na **Fatec Votorantim**, dedicada à criação de soluções web e ao desenvolvimento de projetos multidisciplinares. Nosso foco é aliar boas práticas de programação e metodologias eficientes para entregar resultados consistentes e de alta qualidade.

## 🚀 Nosso Projeto Atual

Atualmente, estamos desenvolvendo o **Site de Governança para o Grupo Panna**.
O projeto tem como objetivo principal estruturar um portal corporativo focado em governança, garantindo uma interface acessível, responsiva e alinhada às necessidades estratégicas do grupo.
